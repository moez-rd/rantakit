# Free forever, with no feature gating

Most file-tool apps charge a subscription or lock their best tools behind a "pro" tier. We decided that Rantakit has no paid tier, no feature gating, no ads, no "pro" build, and no paid cloud companion: every feature is available to everyone. Sustainability comes only from voluntary donations or sponsorship (for example GitHub Sponsors, Saweria, Trakteer), which never change what the app can do and are mentioned in one quiet place in the app, never as a prompt or nag.
