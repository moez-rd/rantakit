# No built-in institution presets

The most common reason people use Rantakit is to meet a portal's file rule (CPNS, LPDP, BPJS, university or job portals). Shipping ready-made presets such as "CPNS – Pas Foto" looks helpful, but these rules change every year, a stale preset can get a user's application rejected, and the project would become the maintainer of government rules. We decided Rantakit ships no institution presets. Instead it remembers the last size limits the user typed and lets users save their own named Presets.
